# DjFah Radio

Ραδιόφωνο με χαρακτήρα: επιλεγμένοι μουσικοί σταθμοί κουλτούρας από 50 χώρες, μόνο με ροές υψηλής ποιότητας.

- **stations.json**: η επιμελημένη λίστα σταθμών. Η εφαρμογή (υπολογιστής και κινητό) τη διαβάζει από εδώ και ανανεώνεται χωρίς νέα εγκατάσταση.
- **Android**: το αρχείο APK βρίσκεται στις [Releases](../../releases/latest).
