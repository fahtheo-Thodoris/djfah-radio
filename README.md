# DjFah Radio

Ραδιόφωνο με χαρακτήρα: επιλεγμένοι μουσικοί σταθμοί κουλτούρας από 50 χώρες, μόνο με ροές υψηλής ποιότητας.

- **Κινητό (Android):** κατέβασε το **DjFah-Radio.apk** από την τελευταία [Release](../../releases/latest).
- **Υπολογιστής (Windows):** το πρόγραμμα εγκατάστασης `Install_DjFah_Radio_v*.bat`.
- **stations.json:** η επιμελημένη λίστα σταθμών. Και οι δύο εκδόσεις τη διαβάζουν από εδώ και ανανεώνονται χωρίς νέα εγκατάσταση.

## Δομή
- `pc/app` – η εφαρμογή (οθόνη + τοπικός διακομιστής Python για Windows). Η ίδια οθόνη χρησιμοποιείται και στο Android.
- `pc/build.py` – φτιάχνει το `.bat` εγκατάστασης: `python pc/build.py Install_DjFah_Radio_vX.bat` (μέσα από τον φάκελο `pc`).
- `android-app` – το έργο Android (Capacitor + εγγενής αναπαραγωγή Media3 με τίτλους, οθόνη κλειδώματος, Shazam).
- `.github/workflows/android.yml` – χτίζει αυτόματα το APK σε κάθε αλλαγή.
